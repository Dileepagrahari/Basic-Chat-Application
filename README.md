# Real-Time Chat Application

A simple real-time chat application that allows multiple connected users to exchange messages instantly using WebSocket communication.

## Features
- Real-time message broadcasting
- Multiple client connections
- WebSocket-based communication
- Automatic message timestamps
- Welcome message on connection

## Tech Stack
- Node.js
- Express.js
- WebSocket (ws)
- HTML, CSS & JavaScript (frontend)

## Installation & Setup

**1. Clone the repository**
```bash
git clone https://github.com/Dileepagrahari/Basic-Chat-Application.git
```

**2. Navigate to the project**
```bash
cd Basic-Chat-Application
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the application**
```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
